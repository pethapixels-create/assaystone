# v0.3.0 — Audit, contracts, and runtime gates

Assaystone 0.3.0 is the first public alpha. It audits existing agent traces for
silent failures, turns findings into acceptance contracts, and runs the same contracts
in CI and at runtime.

## Highlights

- `assaystone audit` for Claude Code transcripts, LangSmith, Langfuse, OpenTelemetry
  GenAI spans, message exports, and trace JSON.
- Artifact reconstruction from `Write` / `Edit` / `MultiEdit`; post-session workspace
  fallback; `--git-preimage` for diff-size and public-API checks.
- Claude Code Stop hook: install, warn/block, per-session dedupe, and
  `.assaystone/hook.json` ignore rules.
- Acceptance contracts, a cost-ordered verifier ladder, `pass / fail / escalate`, and
  evidence refs.
- Mutation testing and backtesting; code/test and ops/refund packs.
- `RuntimeGuard` for irreversible actions: approvals, contract enforcement, shadow mode.
- pytest plugin, GitHub Action, SARIF 2.1.0, JUnit, `--no-evidence`.
- Packaged demos that work after `pip install`; Python 3.10–3.12 CI plus a wheel
  build/install demo job.

## Install

```bash
pip install assaystone
assaystone demo audit
```

## Known limitations

- Alpha. LangSmith / Langfuse / OTel importers are heuristic; export shapes vary.
- `tests.integrity` flags every test-file edit. The Claude Code hook defaults to
  warn; add ignore rules for known-good test edits.
- Post-session diff checks need a `HEAD` commit; `--git-preimage` uses it when present.
- No TypeScript port, hosted dashboard, or pre-action contract subsets yet.
