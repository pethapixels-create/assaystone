# v0.3.1 — Real-session coverage fixes

0.3.1 is driven by an aggregate audit of 162 real Claude Code sessions. Two blind
spots showed up, and both are fixed.

## Changes

- **The Claude Code hook now sees Bash edits.** When `cwd` is the git root, it merges
  working-tree changes into the artifacts, so `sed -i`, `cat >`, `tee`, `patch`, and
  similar edits are audited. Non-git workspaces still use transcript artifacts.
- **The audit step budget moved from 200 to 5,000.** 46/162 real sessions exceeded
  200 steps; 200 was flagging normal long sessions.
- Added `scripts/corpus_audit.py` for read-only aggregate audits of a local transcript
  corpus.
- Added tests for git working-tree auditing and the new step budget.

## Field note

In the 162-session corpus: 39% of sessions edited files, 17% touched test files, but
only one edited tests without source — and 61 sessions wrote files through Bash, 16 of
which had no `Edit`/`Write` artifacts. Details:
[docs/case-study-2026-11.md](../case-study-2026-11.md).

## Install

```bash
pip install --upgrade assaystone==0.3.1
assaystone demo audit
```
