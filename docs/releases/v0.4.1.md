# v0.4.1 — Packaging fix

0.4.0 was published correctly, but its tag was cut before the generated-workflow pin
was updated. 0.4.1 fixes that packaging inconsistency. There are no verifier behavior
changes.

## Changes

- `assaystone init --ci` generates
  `uses: yellowsand1/assaystone@v0.4.1`.
- The README status line, GitHub Action example, and install example point at 0.4.1.
- The package metadata now reflects the 0.4.x release.

## Install

```bash
pip install --upgrade assaystone==0.4.1
assaystone demo audit
```
